01 / OUTCOMES

本周期核心交付

围绕“可运行、可追踪、可恢复、可部署”推进，不只增加页面，也补齐了运行时与持久化边界。

01

双进程架构完成收敛

Access Layer 负责公开 API、会话真相源、目录解析和流式透传；Agent Backend 保持无状态，专注模型、工具、MCP、Skill 与 AG-UI 协议适配。

02

Agent Team 正式落地

Supervisor 先生成带依赖关系的任务 DAG，再按最大并行度调度 Worker；任务工作空间隔离，并支持验收、审批和持久化恢复。

03

定时任务形成闭环

支持单次、每日、每周与 IANA 时区；采用最近到期时间动态休眠，每次运行拥有独立 Session 与 Workspace，结果不污染普通会话列表。

04

权限与沙箱进入产品层

增加默认权限与完全权限语义、HITL 审批、Bash 结构化升级、网络白名单和有界超时，为无人值守自动化建立明确风险边界。

05

实时交互能力增强

AG-UI 时间线统一展示正文、推理与工具；浏览器语音支持输入、连续对话、朗读、打断和取消回滚，后台运行在会话切换后仍可继续。

06

部署与数据边界可交付

补齐脱敏 Docker 镜像、Compose、持久卷与内网访问流程。密钥、Sessions、Skills、Memory、Team 和 Workspace 均不写入镜像层。

04 / QUALITY

质量建设与风险

功能链路已完整，但涉及本机能力与无人值守运行，必须继续把安全与恢复能力当作产品功能。

已建立的工程保障

  • AG-UI start/content/end 生命周期与原始事件顺序形成文档和回归约束。
  • 工具错误结构化返回模型，避免普通失败直接终止整个 run。
  • Session、Team、Automation 工作空间与持久化路径明确隔离。
  • 上下文预算、自动压缩与旧工具结果裁剪降低长会话失控风险。
  • Docker 镜像排除密钥与用户状态，运行数据通过环境变量和卷注入。

当前重点风险

权限规则复杂度

读、写、网络、主机资源和完全权限需继续用能力模型收敛，避免模型通过参数误触发审批。

跨平台沙箱

macOS Seatbelt、Linux sandbox-runtime 与容器运行差异仍需在真实部署机持续验证。

流式 UI 一致性

推理、工具、审批、正文都依赖严格事件顺序和及时绘制，需要覆盖更多中断与后台页场景。

无人值守副作用

定时任务不得自动重放已开始的副作用调用；完全权限必须持续显示高风险提示。
